# API Contracts

This directory contains the machine-readable API specifications and schemas that define the boundary between the FastAPI backend and the React frontend.

- `openapi.yaml`: Canonical OpenAPI 3.0 specification for all REST endpoints (`/api/health`, `/api/dataset/summary`, `/api/preprocessing/preview`, `/api/models`, `/api/metrics`, `/api/predict`).
- `examples/`: Request and response JSON payloads for contract verification and frontend mocking.
